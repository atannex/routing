# atannex/routing

[atannex/routing](https://packages.atannex.com) is a [Laravel](https://laravel.com/) package for defining and managing [application routes](https://laravel.com/framework/docs/routing) directly on [controller classes and methods](https://laravel.com/framework/docs/controllers) using [PHP](https://www.php.net/) [attributes](https://www.php.net/manual/en/language.attributes.overview.php). It keeps route declarations close to the actions that handle [requests](https://laravel.com/framework/docs/requests), reducing manual [route](https://laravel.com/framework/docs/routing) definitions and making web pages, [APIs](https://laravel.com/framework/docs/routing#api-routes), and modular applications easier to organize.

The package supports [standard HTTP routes](https://laravel.com/framework/docs/routing#available-router-methods), [resource controllers](https://laravel.com/framework/docs/controllers#resource-controllers), [single-action controllers](https://laravel.com/framework/docs/controllers#single-action-controllers), [route groups](https://laravel.com/framework/docs/routing#route-groups), [URL prefixes](https://laravel.com/framework/docs/routing#route-prefixes), [route names](https://laravel.com/framework/docs/routing#named-routes), [domains](https://laravel.com/framework/docs/routing#subdomain-routing), and [shared middleware](https://laravel.com/framework/docs/middleware#middleware-groups). It [discovers controllers in configured directories](https://packages.atannex.com) and [orders routes by specificity](https://packages.atannex.com) to reduce matching conflicts. [Parameter constraints](https://laravel.com/framework/docs/routing#parameters-regular-expression-constraints), [model binding](https://laravel.com/framework/docs/routing#route-model-binding), and [validation](https://laravel.com/framework/docs/validation) help determine which requests a route accepts and how their data is processed.

It allows developers to apply Laravel's [authentication](https://laravel.com/framework/docs/authentication), [authorization](https://laravel.com/framework/docs/authorization), [email verification](https://laravel.com/framework/docs/verification), [signed URL checks](https://laravel.com/framework/docs/urls#signed-urls), [password confirmation](https://laravel.com/framework/docs/authentication#password-confirmation), and [rate limits](https://laravel.com/framework/docs/routing#rate-limiting) through attributes. It also supports [response caching headers](https://laravel.com/framework/docs/responses#cache-control-middleware), [JSON error responses](https://laravel.com/framework/docs/errors#rendering-exceptions-as-json), and [webhook signature verification](https://packages.atannex.com), making it useful for managing access to application endpoints and handling integrations with external services.

The package helps maintain applications as their routes change through [redirects](https://laravel.com/framework/docs/routing#redirect-routes), [fallback pages](https://laravel.com/framework/docs/routing#fallback-routes), [conditional route registration](https://packages.atannex.com), and [endpoint deprecation](https://packages.atannex.com). Simple [view routes](https://laravel.com/framework/docs/routing#view-routes) and redirects can be configured without dedicated controllers. Attribute-based [scheduling](https://laravel.com/framework/docs/scheduling) and [broadcast channel registration](https://laravel.com/framework/docs/broadcasting#defining-channel-classes) also keep recurring tasks and [channel access rules](https://laravel.com/framework/docs/broadcasting#authorizing-channels) close to the classes that handle them.

For larger applications, the package supports [custom attributes](https://packages.atannex.com) and [configurable discovery](https://packages.atannex.com) across modules and additional directories. [Developer tools](https://packages.atannex.com) help [inspect registered routes](https://packages.atannex.com), [identify duplicates and unreachable endpoints](https://packages.atannex.com), [convert existing controller routes into attribute declarations](https://packages.atannex.com), and [cache discovery results](https://packages.atannex.com). Its routes use [Laravel's router](https://laravel.com/framework/docs/routing), preserving compatibility with [route names](https://laravel.com/framework/docs/routing#named-routes), [URL generation](https://laravel.com/framework/docs/urls), [middleware](https://laravel.com/framework/docs/middleware), [model binding](https://laravel.com/framework/docs/routing#route-model-binding), and [route caching](https://laravel.com/framework/docs/routing#route-caching).

For the full package documentation, including installation instructions, configuration options, and detailed usage examples, visit the [Atannex Packages website](https://packages.atannex.com).
